preserved as an archived development diagnostic. Its grader-validity no-go
stands, but the earlier ceiling label is withdrawn: a single correct Sol run
establishes tractability, not saturation.

The v0.8 verifier was initially repaired using the two preserved v0.7.2
trajectories, then tested against all five independently preserved v0.7.1
trajectories and case-wide controls. It
scores each primary and follow-up calculation separately, does not allow an

mission cannot coexist with a first decision-critical failure.

decision record now includes development stage, disposition, allowed use,
unresolved gates, prohibited use and required next evidence. The old trajectories
are migrated only for zero-cost replay with field-level provenance; future v0.8

conditions. Source packet, truth, sealed outcome and Case 3 mechanism-return

retained only as a post-MVP roadmap; none of the seven proposed new

## Zero-cost verifier-architecture repair

The explicitly authorized repair preserved snapshot 01, the raw Case 2 95/fail
record and the interrupted Case 3 state. It did not change a public packet,
private truth, prompt, tool, action rule or scientific version. An archival tar
also preserves the snapshot-01 repair-relevant source files.

Every mission-critical property now has one declared authority. Numerical
results come only from saved artifacts that the hidden verifier independently
recomputes. Tool actions and timing come only from the event record. Supported,
prohibited and asserted claims come only from the disclosed machine claim-ID
fields. Development stage and disposition come only from their disclosed enums.
Allowed use, prohibited use, unresolved gates, required evidence, named belief
hypotheses and evidence prose remain available for professional audit but cannot
change a mission score.

The full audit removed nine duplicated or prose-derived scoring paths. The exact
unchanged Case 2 submission replays as 100/100 and complete mission success. This
is explicitly a development verifier replay, not a retroactive frozen score; the
historical 95/fail is still the immutable execution result and remains invalid
for model interpretation.

All 35 existing controls and four additional naturalistic model-language
fixtures pass. Missing or wrong claim IDs still fail even when expected words
appear in prose, while reasonable paraphrases cannot alter correct machine
claims. The complete local gate passed 511 tests, lint, project doctor, audit
consistency and Docker isolation with zero API requests and zero spend.

Interrupted Case 3 is not exactly resumable. C1-C4 checkpoints, revealed

complete message bodies, assistant reasoning payloads, tool arguments/results,
