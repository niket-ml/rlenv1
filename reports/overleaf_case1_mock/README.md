# Synthetic Case 1 presentation mock

Upload both LaTeX files to Overleaf and compile `main.tex` with pdfLaTeX. The ZIP contains all required source files.

`case1_mock.tex` is the replacement section. It uses the existing report's commands and drawing styles. The standalone wrapper adds a synthetic-results warning to every page.

This is an illustrative design, not a modification of the evaluated environment. The mock retains the original task question and the 134-record/124-person setting. It adds hypothetical patient-ID inconsistencies and a response spreadsheet that mixes assessment times. The source documents needed to resolve those problems are part of the proposed scenario, not files already implemented for the real case.

Model 1 and Model 2 are fictional placeholders here. They do not map to the identification key in the empirical report. Their scores of 62 and 57 are assigned for this demonstration. The illustrative allocation sums to those values but is not the deployed rubric. No API costs or measured biological statistics are copied into the mock. Do not present these scores as observed model performance.

The real report, environment, graders and trajectories remain unchanged. No model calls were made.

The layout targets three pages. Static source checks were performed. No local TeX compiler is available, so rendered layout must be checked in Overleaf.
