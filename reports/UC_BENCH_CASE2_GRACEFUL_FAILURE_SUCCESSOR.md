## Causal diagnostics and strict success

```text
Public pre-outcome evidence ──> committed cohort/plan ──> prospective eligibility
           │
           └──> registered sources ──> reconstructed analysis table
                                            ├── discrimination + uncertainty
                                            ├── probability + calibration
                                            ├── threshold utility
                                            └── context robustness
Purchased evidence ──> saved follow-up calculations + explicit effect assessment

Eligible scientific evidence + explicit supported claims ──> bounded final decision
```

This shows evidence flow, not a required order of scientific methods. The emitted
`dependency_dag` records the exact property dependencies. Invalid prospective
binding blocks decision eligibility, not independent numerical inspection.
Failure in one numerical sibling does not erase another. Conservative property-level
eligibility and claim scope are separate from the diagnostic arithmetic score.

| Property | Direct diagnostic evidence |
|---|---|
| Prospective design/integrity | Complete hashed pre-outcome manifest and committed plan/event adherence. |
| Saved artifact chain | Registered source-linked table and saved output for each required calculation; actual supplied sources verified, directly or through registered lineage. |
| Entity/dependence | Raw-source membership reconstruction and correct dependence treatment, assessed separately. |
| Discrimination/uncertainty | Correct saved point estimate and committed interval, separately credited. |
| Probability/calibration | Independently recomputed required probability-accuracy and calibration results. |
| Utility | Saved policy/threshold calculation recomputed from its declared inputs. |
| Context robustness | Required context result and source-linked context audit, separately assessed. |
| Follow-up | Explicit relevance, authenticated return, recomputed result, valid calculations and saved materiality/effect judgment. Purchase alone is insufficient. |
| Bounded decision/claims | An actual final submission with supported scope; no intermediate note is promoted to a final decision. |

The existing nine property weights are unchanged. Within properties, required
evidence items receive equal diagnostic fractions. The five required numerical
families cannot disappear from denominators if an agent omits a criterion.
Unrelied-on optional calculations do not enter primary denominators. Output
records include exact item evidence, local faults and dependency reasons.

Strict mission success, requirement outcomes, first strict failure and reliability
come from the unchanged evaluator. A missing final submission means strict failure
and reliability zero, even if registered intermediate calculations are correct.
Registered work-index contents must match the persisted index exactly. Conflicting
registrations are quarantined; unregistered files receive discovery annotations only.
